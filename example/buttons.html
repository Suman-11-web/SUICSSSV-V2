Component Library

Interactive Buttons

A comprehensive suite of highly tactile, accessible button primitives. Engineered with fluid padding, perceptual contrast, and hardware-accelerated micro-interactions.

Semantic Variants

Core styles for primary, secondary, and destructive actions.

<!-- SUI Core Button Variants -->
<button class="sui-btn sui-btn-primary sui-hover-lift sui-active-push">Primary Action</button>
<button class="sui-btn sui-btn-secondary sui-hover-lift sui-active-push">Secondary</button>
<button class="sui-btn sui-btn-outline sui-hover-lift sui-active-push">Outline Variant</button>
<button class="sui-btn sui-btn-ghost sui-hover-lift sui-active-push">Ghost Button</button>
<button class="sui-btn sui-btn-danger sui-hover-lift sui-active-push">Delete Repository</button>

Volumetric Sizing

Fluid size variants that maintain perfect aspect ratios and touch targets.

<!-- SUI Size Modifiers -->
<button class="sui-btn sui-btn-primary sui-btn-sm">Small (sm)</button>
<button class="sui-btn sui-btn-primary">Default (base)</button>
<button class="sui-btn sui-btn-primary sui-btn-lg">Large Scale (lg)</button>

</button>
