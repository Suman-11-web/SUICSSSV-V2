Advanced Architecture

Zero JS.
Pure CSS Compute.

This entire documentation page operates without a single line of JavaScript logic for its components. Anchor positioning, trigonometry, masonry grids, and height transitions are rendered natively by the engine.

1. Command Menus (Anchor Positioning)

Popovers dynamically calculate their X/Y coordinates to stay attached to their trigger, flipping automatically if they hit the screen edge.

  • Profile & Visibility
  • Twilio API Config
  • Logout
<!-- HTML5 popover target links the button to the menu natively -->
<button popovertarget="dropdown" class="sui-anchor">Open Menu</button>

<!-- CSS 'position-anchor' keeps this bound to the button -->
<div id="dropdown" popover class="sui-popover sui-dropdown-menu">
  <ul>
    <li>Profile Settings</li>
    <li>Logout</li>
  </ul>
</div>

3. Container Style Queries

Components now read the CSS variables of their parent wrapper, allowing a single component to restructure itself based on contextual logic.

Light Mode Context
I inherited `--theme: light` from my wrapper.
Dark Mode Context
I inherited `--theme: dark` from my wrapper and re-styled myself automatically. 
/* In advanced.css: */
@container style(--theme: dark) {
  .sui-smart-card {
    background: #1a1a1a;
    color: white;
  }
}

4. Field Sizing (Auto-expand Forms)

The `field-sizing: content` specification allows textareas and inputs to natively grow as the user types. Type a long paragraph below to test it.

<!-- No JS required. field-sizing handles exact pixel height natively -->
<textarea class="sui-input sui-textarea-auto"></textarea>

5. Interpolate Size (Height: Auto)

After 25 years, CSS can finally animate smoothly from `height: 0` to `height: auto`. Click the native `

` accordion below.

Advanced CSS Interpolation

This transition is hardware accelerated.

The browser computes the height required for the content inside, and smoothly animates to that exact keyword value.

<!-- CSS uses 'interpolate-size: allow-keywords' for the magic -->
<details class="sui-accordion">
  <summary>Click to expand</summary>
  <div class="sui-accordion-content">
    <p>Smooth height: auto animation!</p>
  </div>
</details>
