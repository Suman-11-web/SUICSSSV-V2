Build interfaces with Sui.css.

A lightweight, utility-first and component-ready CSS framework designed to help you build modern responsive interfaces faster.

v2.1.0 CSS Engine Responsive Utility-first
01

Introduction

Sui.css is a reusable CSS framework built around utilities, layout primitives, components, design tokens and animations.

⚡

Lightweight

Use only the classes required by your interface while keeping your markup simple.

🧩

Modular

Sui.css separates reset, tokens, layout, utilities, and components into layers.

📱

Responsive

Build layouts that adapt across mobile, tablet and desktop screen sizes.

🎨

Customizable

Design tokens allow you to customize colors, spacing, typography, and radius.

02

04

Design Tokens

Design tokens provide centralized values for your framework. Your token implementation lives inside src/layers/tokens.css.

💡
Why tokens?

Instead of repeating raw values throughout your stylesheet, define reusable variables once and reference them throughout Sui.css.

CSS 
:root {
    --sui-brand-hue: 250;
    --sui-primary-500: oklch(60% 0.2 var(--sui-brand-hue));
    --sui-success: oklch(65% 0.15 150);
    --sui-danger: oklch(60% 0.2 25);
    
    --sui-space-2: 0.5rem;
    --sui-space-4: 1rem;
    --sui-radius-md: 0.5rem;
}
05

Layout

Use Sui layout utilities to construct responsive page structures without repeatedly writing custom CSS.

Class Purpose
.sui-flexCreates a flex container.
.sui-gridCreates a grid container.
.sui-items-centerCenters items on the cross axis.
.sui-justify-centerCenters content horizontally.
.sui-justify-betweenPlaces content at opposite ends.
.sui-gap-4Applies a framework spacing value.
HTML 
<div class="sui-flex sui-items-center sui-justify-between sui-gap-4">
    <div>Brand</div>
    <nav>Navigation</nav>
</div>

Accessible Modals & Dialogs v2.1.0 NEW

Includes focus trapping, ESC key listener, backdrop blur, and standardized header/body/footer structure.

HTML 
<!-- Open Trigger -->
<button class="sui-btn sui-btn-primary" data-sui-modal-target="demoModal">Launch Modal</button>

<!-- Modal Overlay -->
<div id="demoModal" class="sui-dialog-overlay">
    <div class="sui-dialog sui-dialog-lg sui-animate-spring-up">
        <div class="sui-dialog-header">
            <h3 class="sui-dialog-title">Dialog Title</h3>
            <button class="sui-dialog-close" data-sui-modal-close>&times;</button>
        </div>
        <div class="sui-dialog-body">Modal content body.</div>
        <div class="sui-dialog-footer">
            <button class="sui-btn sui-btn-outline" data-sui-modal-close>Cancel</button>
            <button class="sui-btn sui-btn-primary">Save</button>
        </div>
    </div>
</div>

Toasts & Dismissible Alerts v2.1.0 NEW

Trigger notifications programmatically with status icons, or dismiss banners with data attributes.

JAVASCRIPT & HTML 
// JS Toast Trigger
SUI.toast.show({
    title: 'Success',
    message: 'Operation completed successfully.',
    type: 'success' // success | danger | warning | info
});

<!-- Dismissible Alert Banner -->
<div class="sui-alert sui-alert-success">
    <span class="sui-alert-icon">✓</span>
    <div class="sui-alert-content">All changes saved.</div>
    <button class="sui-alert-close" data-sui-dismiss="alert">&times;</button>
</div>

09

Responsive Design

Build interfaces that adapt to different viewport sizes using the responsive utilities provided by Sui.css.

⚠
Mobile First Architecture

Sui.css uses mobile-first media queries. Use the md: prefix to apply changes on desktop and tablet screens.

HTML 
<!-- Stack on mobile, flex row on desktop -->
<div class="sui-flex sui-flex-col md:sui-flex-row">
    <div>Content</div>
    <div>Sidebar</div>
</div>
10

Customization

Customize Sui.css by overriding design tokens in your own stylesheet.

CSS 
:root {
    --sui-brand-hue: 280; /* Changes entire framework palette */
    --sui-radius-md: 14px;
}
🧠
Keep customization separate

Avoid editing the generated dist/sui.min.css directly. Keep project-specific overrides in your own stylesheet after importing Sui.
